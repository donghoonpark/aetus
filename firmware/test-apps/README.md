# AETUS Firmware Test Apps

This directory contains validation firmware, not reusable package source and not user-facing examples.

## Apps

| App | Purpose | Automation |
| --- | --- | --- |
| `qemu-telemetry` | SIL/QEMU fixture that emits a nanopb protobuf stream over UART so the ingest E2E test can POST the exact firmware-generated bytes into the backend stack. | Compile-checked by `Firmware Test Apps Build`; full QEMU-to-PostgreSQL flow is run by the manual `ESP32 QEMU E2E` workflow. |
| `esp32c5-upload-smoke` | HIL firmware for a physical ESP32-C5 board. It consumes `firmware/esp32-aetus`, connects to Wi-Fi, syncs RTC, uploads telemetry, and can run randomized continuous upload mode. | Compile-checked by `Firmware Test Apps Build`; flash/monitor/runtime checks stay local because they require a board, Wi-Fi, and lab credentials. |

Keep new validation-only firmware here so `firmware/esp32-aetus` remains the portable embedded stack and `firmware/examples` remains focused on copyable user examples.
